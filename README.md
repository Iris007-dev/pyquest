# 零基础学 Python · PyQuest

PyQuest 是面向零基础学习者的中文 Python 交互闯关网站。它把概念讲解、动手运行、分章练习和复盘放在同一个页面中。打开网站即可开始，不需要先在电脑上安装 Python。

## 它适合谁

- 从未学过编程，希望先弄明白变量、条件、循环等基础概念的人。
- 看过教程却不知道怎样开始写代码，希望边学边练的人。
- 想按章节巩固知识，并练习常见笔试、面试题的人。

## 主要优点

1. **循序渐进的路线**：14 阶段课程地图、57 个文字知识点，从基本语法逐步走向函数、数据结构和实际应用。
2. **面向小白的文字讲解**：用中文解释概念、代码为什么这样写，以及容易混淆的地方。教程是可阅读的文字，而不是只能放大的课件图片。
3. **真正运行 Python**：代码实验室通过 Pyodide 在访问者自己的浏览器中执行 Python，展示真实输出；运行超时会结束该次执行。
4. **练习时有台阶**：200 道分章练习配有逐步提示、参考答案和解析，做题时可以先尝试，再按需查看提示。
5. **即时反馈与复盘**：部分挑战题提供自动判题；错题和学习进度保存在当前浏览器，方便回头练习。
6. **手机也能学**：页面适配较小屏幕，部署为静态网站后可通过链接访问。

## 在线使用

启用 GitHub Pages 后，在仓库的 **Settings → Pages** 中查看网站地址。打开后从“课程地图”选择章节，也可以直接进入“代码实验室”运行第一段程序。

## 本地预览

在本目录运行：

```powershell
python -m http.server 8012
```

然后打开 `http://127.0.0.1:8012/`。第一次运行 Python 代码时需要联网下载 Pyodide 组件，可能稍慢。直接双击 `index.html` 打开本地文件，不一定能正常加载代码执行环境。

## 部署到 GitHub Pages

把本目录的**全部文件**放在仓库根目录，确保 `index.html` 位于根目录。进入 **Settings → Pages**，选择 **Deploy from a branch**，再选择 `main` 和 `/(root)`，保存即可。

## 使用说明

- 代码在浏览器内运行，学习记录保存在当前浏览器；换设备后不会自动同步。
- 浏览器内的 Python 与电脑上安装的 Python 不完全相同。需要本机文件、桌面界面或额外第三方包的练习，请在自己的 Python 环境中完成。
- 原始 PDF、页图和原始练习 `.py` 文件不包含在这个公开仓库版本中。

本项目当前以学习和演示为目的。课程内容与功能会继续完善。
