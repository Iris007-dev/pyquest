# 零基础学 Python · PyQuest

**PyQuest** 是面向零基础学习者的中文 Python 交互学习网站。它把“读懂概念 → 预测结果 → 亲手写代码 → 查看反馈 → 回顾错题”串成一条学习路线。第一次体验无需安装 Python，打开网页就能阅读教程、写代码和做练习。

> 当前公开版包含 **14 阶段课程地图、10 章文字教程中的 57 个知识点、200 道分章练习**，以及 **3 道带自动判题的工作场景代码题**。地图展示长期学习方向；详细教程按 10 章组织，并非 14 套独立教材。

## 适合谁

- **完全零基础**：还不清楚变量、列表或函数是什么，想从最简单的程序开始。
- **看过教程却写不出来**：需要在讲解旁边立刻运行代码，通过提示独立完成题目。
- **想巩固知识、准备面试**：希望练习常见边界条件、返回值和代码思路的表达。
- **主要用手机学习**：希望随时读教程、做短题、回顾错题；较长的程序仍建议用电脑键盘编写。

## 为什么选择 PyQuest

### 1. 从“为什么”开始讲，而不是堆术语

每个知识点先给出学习目标，再用中文解释概念、示例和容易弄错的地方。比如，变量的 `=` 与数学等号有什么不同，字符串的索引和切片怎样取值，为什么某些对象不能原地修改。教程是可阅读、可搜索的文字，不依赖放大的课件图片；部分概念还有进一步讲解和 Python 官方文档链接。

### 2. 学习路线清楚，知道先学什么

14 阶段地图列出各阶段的主题、前置知识与学习深度。从环境与表达式、容器、分支循环、函数，逐步走向异常处理、面向对象、算法、测试、自动化与综合项目。刚开始可以顺着地图读；有一点基础的读者也能从对应知识点进入。

### 3. 先预测、再运行，检验自己是否真正理解

课程示例先展示代码，让你尝试猜输出，再展开预期结果。点击“用真实 Python 运行”或“把这段代码送去实验室”，代码会进入实验室。改动一个数字、一行判断或一个缩进，就能看到结果怎样变化，不用死记例题。

### 4. 浏览器内真正执行 Python

代码实验室通过 **Pyodide 和 Web Worker** 在访问者自己的浏览器中执行 Python，显示程序输出或报错。这是真实执行，不是预先写好的假结果。首次运行需要联网下载运行组件；单次执行有超时处理，遇到无限循环后还可以继续运行新代码。

### 5. 200 道练习跟着知识点走

练习就在相关教程旁边，读完一小节就能动手。题目覆盖输出预测、基本语法、字符串与容器处理、函数等内容。网站会记住已提交的题目，并保存每道题正在写的代码草稿，方便下次接着做。

### 6. 不会做时，提示分两步给

每道分章练习先提供**思路提示**，仍写不出来时再提供**语法提示**。提示逐步展开，不会一开始就亮出完整答案。你可以先自己尝试，再按需要获得帮助。

### 7. 答案不只给代码，还讲清写法

输入并运行自己的代码后，页面会显示参考答案和文字解析。解析解释思路、步骤、语法与常见错误，帮助你弄懂“为什么这样写”。开放题会显示你的实际运行结果，仍需结合题意、参考解法和边界输入自行核对；**200 道练习并非全部自动判题**。

### 8. 章节理解题即时反馈

文字教程的每一章都设有理解检验。选答案后立即看到对错和原因；答对记录章节进度，答错进入错题记录。这样能发现自己是读懂了，还是只记住了某个例子。

### 9. 工作场景题练习真实边界

当前有 3 道带自动判题的代码题：**电商订单汇总、库存录入校验、二分查找左侧插入位**。判题会检查常规示例，也会检查空输入、重复值、负数或零值等边界，并关注返回值类型与是否意外修改输入。提交后能看到通过数量和失败反馈，再修改代码重试。

### 10. 进度和错题随时回看

页面显示章节理解题、200 题提交数和实战题的学习进度。错题本记录理解题和自动判题中的错误，并提供回到讲解的入口。进度、题目草稿和提示展开状态保存在**当前浏览器**，关闭页面后回来仍可继续。

### 11. 手机与电脑都方便使用

页面针对小屏幕调整了教程侧栏、题目列表和代码区域。手机适合阅读、做短题和复盘，电脑更适合输入较长的程序。部署为公开网站后，只要有网址就能访问，不要求项目作者的电脑一直开机。

### 12. 源码公开，部署和运行方式透明

网站由 HTML、CSS 和 JavaScript 组成，可部署到 GitHub Pages 等静态托管平台。访问者提交的 Python 代码在其浏览器中运行；网站服务器不会替访问者执行代码。仓库保留了教程、题库页面和运行器源码，方便查看具体实现。

## 第一次使用：按这 6 步开始

1. 打开网站，点击“开始阅读第一个知识点”，或从“课程地图”选一个阶段。
2. 阅读“读完你能做到”和“从零讲起”，遇到陌生术语先看对应例子。
3. 阅读代码示例，先猜输出，再展开预期结果。
4. 把示例送去“代码实验室”，运行后改动一小处，观察输出或错误。
5. 做课后题；卡住时依次看两级提示，再运行自己的代码并阅读答案解析。
6. 完成章节理解检验；有余力时做工作场景题，最后到错题本复盘。

建议每天只选一个小知识点，读懂后改几次代码，再做题。能用自己的话解释每一行，比一次刷很多题更有帮助。

## 本地运行

在仓库根目录打开终端，运行：

```powershell
python -m http.server 8012
```

再打开 `http://127.0.0.1:8012/`。第一次点击“运行代码”时需要联网下载 Pyodide 组件，可能需要等待。请通过本地服务器访问，不要只双击 `index.html`；浏览器对本地文件页面的 Worker 加载有限制。

## 发布到 GitHub Pages

本仓库已把 `index.html` 放在根目录。仓库拥有者进入 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，把分支设为 `main`、目录设为 `/(root)` 并保存。部署完成后，以 Pages 设置页显示的网址为准。只把文件上传到 GitHub 仓库，不会自动获得公开的网站网址。

## 使用边界

- **设备间不自动同步**：学习记录存在浏览器的 `localStorage` 中。清除浏览器数据或换设备后，记录可能无法找回。
- **练习反馈形式不同**：200 道分章练习提供代码运行与参考解法，开放题需要自行核对；3 道实战题提供自动判题。
- **浏览器 Python 有适用范围**：需要读取电脑真实文件、调用桌面程序或使用额外第三方包的任务，应在自己电脑安装的 Python 环境中完成。个别图片处理题尤其如此。
- **首次运行依赖网络**：Pyodide 及网页字体等资源需联网加载，较慢的网络可能影响首次体验。
- **公开版文件范围**：原始 PDF、PDF 页图和原始练习 `.py` 文件没有放进这个公开仓库；网站提供整理后的文字教程和练习内容。

PyQuest 仍在持续完善。欢迎从第一段 `print()` 开始，运行、修改、观察，再慢慢写出自己的程序。
